## 2. Detailed File Structures & Responsibilities

### 1. `MorningStockModal.tsx` (Morning: "Add Morning Stock" / Mandi Bill)
- **Backend Endpoint:** `POST /api/vendor/wholesale/bill`
- **Purpose:** Ingests wholesale morning purchases at 8:00 AM without requiring pre-set retail prices. Sets up wholesale unit cost basis so the app can compute true take-home gross profit at night.
- **Props:**
  - `visible: boolean`, `onClose: () => void`, `apiBaseUrl: string`, `onStockAdded?: (summary: { items: any[]; totalCost: number; isCash: boolean }) => void`.
- **Inputs & Controls:**
  - **Quick Item Chips:** Potato (*Aalu*), Tomato (*Tamatar*), Onion (*Pyaaz*), Cooking Oil, Spices & Masala, plus custom item entry.
  - **Quantity & Unit:** Numeric input with unit toggle (`kg`, `litre`, `quintal`).
  - **Rate Paid:** Per-unit wholesale rate (e.g. ₹14/kg) with live calculated total bill (e.g. 50 kg × ₹14 = ₹700).
  - **Payment Method Toggle:** "Paid in Cash Now" (deducts physical drawer cash) vs. "Pay Later (Mandi Udhaar)" (creates supplier liability).
- **Confirmation Action:** "Save Stock & Start Day" triggers API call and inserts an itemized wholesale bill into recent transactions.

### 2. `UpiEventsModal.tsx` (Daytime: "Online Payments" / Soundbox Feed)
- **Backend Endpoint:** `POST /api/vendor/upi/event`
- **Purpose:** Displays live and simulated UPI payments, automatically separating legitimate stall revenue from personal transfers and neighbor soundbox noise.
- **Props:**
  - `visible: boolean`, `onClose: () => void`, `apiBaseUrl: string`, `onUpiPaymentConfirmed?: (amount: number, isSale: boolean) => void`.
- **3 Automatic Status Classifications:**
  1. **Confirmed Shop Sale** (Green check badge): Matches QR code transaction and soundbox chime (+₹30). Added directly to shop revenue.
  2. **Personal Money from Family** (Blue shield badge): e.g. +₹2,000 sent by sister. Kept strictly isolated in personal capital/equity, leaving shop accounting untainted.
  3. **Neighbor's Soundbox Ignored** (Gray warning badge): e.g. ₹50 chime heard from adjacent tea stall. Quarantined with zero ledger impact.
- **Simulation Actions:** One-tap test buttons to inject and verify each of the 3 real-world scenarios on demand.

### 3. `SyncModal.tsx` (Offline Sharing: "Sync with Helper Phone")
- **Backend Endpoint:** `POST /api/vendor/sync`
- **Purpose:** Merges transaction ledgers between two stall helpers or family members using offline Bluetooth mesh / local synchronization without internet access.
- **Props:**
  - `visible: boolean`, `onClose: () => void`, `apiBaseUrl: string`, `onSyncComplete?: (mergedCount: number) => void`.
- **UI & Flow:**
  - Shows nearby discovered devices (e.g., "Ramesh's Phone (Stall Helper)").
  - "Combine Today's Sales (Bluetooth)" initiates pairwise CRDT delta reconciliation.
  - Live progress feedback and summary confirmation.

### 4. `EODReconciliationModal.tsx` (Night: "Close Register / Count My Cash")
- **Backend Endpoint:** `POST /api/vendor/eod/reconcile-batch`
- **Purpose:** Reconciles the vendor's physical cash drawer against speech-discovered sales and wholesale COGS in a single 2-second Qwen SLM batch pass.
- **Props:**
  - `visible: boolean`, `onClose: () => void`, `apiBaseUrl?: string`, `uncommittedHypotheses?: AudioHypothesisBundle[]`, `confirmedUpiTotal?: number`, `onReconciliationComplete?: (result: EODReconciliationResult) => void`.
- **Inputs:**
  1. "Morning cash you started with (₹)" (e.g., ₹500 float).
  2. "Cash in your drawer/pocket right now (₹)" (e.g., ₹3,565).
  3. "Cash spent on stall today (ice, gas, tea) (₹)" (e.g., ₹200).
- **Result Output (The Settlement Report):**
  1. **Real Take-Home Profit Banner:** Big bold Electric Lime/Forest Green number (e.g. ₹1,340.00, 38% margin) showing Net Sales minus Wholesale Mandi Cost.
  2. **Cash Match Status Box:**
     - `BALANCED`: "Perfect Match! Every rupee in your drawer matches today's sales."
     - `SMALL_DIFFERENCE`: "₹10 difference — likely coin change or free chilies."
     - `CASH_TO_CHECK`: "₹50 missing — did you forget an unrecorded stall expense?"
  3. **Items Sold Summary:** Itemized list of discovered quantities and average prices (e.g. Tomatoes: 18.5 kg sold @ ₹30/kg; Potatoes: 42.0 kg sold @ ₹25/kg).

### 5. `LossModal.tsx` (Stock Loss: "Spoiled / Unsold Stock")
- **Backend Endpoint:** `POST /api/vendor/loss`
- **Purpose:** Estimates and attributes spoiled, unsold, or family-consumed produce based on daily temperature and exposure time.
- **Props:**
  - `visible: boolean`, `onClose: () => void`, `apiBaseUrl?: string`, `onCalculate?: (spoilage: number, eating: number, theft: number) => void`.
- **Attribution Breakdown:**
  - Rotten in afternoon heat (e.g., 43.8%).
  - Family dinner / stall worker food (e.g., 47.4%).
  - Roadside dust / handling loss / theft (e.g., 8.8%).

### 6. Daytime Shift Toggle & Live Listening Status Card (`App.tsx`)
- **Backend Service:** `core/perception/unified_audio_stream.ts`
- **UI Elements:**
  - **Live Indicator Dot:** Pulsing green (`#10B981`) when listening is active ("Shop Open • Listening for Sales") vs. neutral gray when paused ("Shop Paused • Offline").
  - **Subtitle Note:** "Safe in pocket — zero battery drain."
  - **Shift Toggle Button:** One-tap pill to "Pause" or "Start Day".
  - **Live Dialogue Preview Bubble:** Subtle speech bubble previewing the latest heard dialogue (e.g. `💬 Customer: 1 kilo tamatar do → Stall: ₹30`).

### 7. Daytime 90% STT Confirmation Alert Banner (`App.tsx`)
- **Backend Logic:** `REQUIRES_VENDOR_CONFIRMATION` trigger when speech confidence falls below 90%.
- **UI Elements:**
  - High-visibility Soft Lime card (`#F1FFE5`) with forest green border.
  - Ear icon badge and title: **"Did you hear right?"**
  - Prompt: *"Did the customer ask for 1 kg Tomatoes for ₹30?"*
  - Dialogue transcript quote preview.
  - Two one-tap actions:
    1. **"Yes, Correct (+₹30)"** (Electric Lime button) $\rightarrow$ Instantly adds the sale to drawer cash and activity.
    2. **"No, Ignore"** (Neutral white/gray button) $\rightarrow$ Discards noisy acoustic garbage with zero false sales.

### 9. Top Header & Shop Profile Architecture (`App.tsx`)
- **Purpose:** Replaces static "Gross Balance" label at the top-left with the vendor's registered stall/shop name dynamically fetched from the database.
- **Data Source:** Backend `GET /api/vendor/shop` (and `GET /api/vendor/state`), backed by SQLite `resolved_entities` CRDT LWW view (`entity_type IN ('vendor', 'business')`).
- **Offline Resilience:** Defaults gracefully to cached/canonical stall name (`Akash Chai & Poha Stall`) when running without an active Wi-Fi or server connection.
- **Dynamic API Host Discovery:** Uses `getApiBaseUrl()` backed by `Constants.expoConfig?.hostUri` to dynamically resolve the computer's LAN IP when running on physical Android/iOS devices via Expo Go, eliminating `localhost` connection failures.

## 3. UI Design Tokens & Styling Guide

- **Primary Brand Color:** Deep Forest Green (`#073B3A`)
- **Accent High-Energy Color:** Electric Lime (`#E2FD52`)
- **Light Tint Backgrounds:** Soft Lime Tint (`#F1FFE5`), Soft Mint (`#F8FBFA`)
- **Border / Divider:** Soft Sage Border (`#DDECE7`), Neutral Gray (`#E5E7EB`)
- **Typography:**
  - Headings: Heavy 800/900 weight, -0.3 tracking.
  - Body: 500/600 weight, 18–20 line height.
- **Elevation / Radius:**
  - Modals: 24–28px rounded corners, bottom sheet slide or fade.
  - Buttons: 18–20px rounded pill buttons with slight glow shadows.
  - Action Squircles: 20px rounded cards in Deep Forest Green with Electric Lime icon boxes.
